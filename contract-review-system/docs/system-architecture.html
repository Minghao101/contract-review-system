LangChain Community

langchain-community

Ollama — 本地模型回退方案。

本项目怎么用 LangChain？
项目没有用 LangChain 的 Agent/Chain/AgentExecutor 高层抽象，而是： 1) 用 ChatAnthropic 作为 LLM 调用层 2) 用 SystemMessage + HumanMessage 构建 prompt 3) 用 llm.ainvoke(messages) 异步调用 4) 用 llm.with_structured_output() 做意图识别（Function Calling） 5) 所有 Agent 调度、路由逻辑全部手写在 MultiTurnHandler 中

3. LLM 工厂 — llm_factory.py

统一管理 LLM 实例，所有 Agent 通过 get_llm() 获取

src/utils/llm_factory.py
class LLMFactory: def __init__(self): self.settings = get_settings() self._llm: Optional[BaseLLM] = None # 单例缓存 def create_llm(self, provider=None) -> BaseLLM: provider = provider or self.settings.LLM_PROVIDER if provider == "anthropic": return ChatAnthropic( model=self.settings.LLM_MODEL, # "mimo-v2.5" api_key=self.settings.LLM_API_KEY, base_url=self.settings.LLM_API_BASE, # MIMO 代理 temperature=self.settings.LLM_TEMPERATURE, # 0.3 max_tokens=self.settings.LLM_MAX_TOKENS, # 10000 ) def get_llm(self) -> BaseLLM: if self._llm is None: self._llm = self.create_llm() # 懒加载 + 单例 return self._llm # 全局便捷函数 def get_llm() -> BaseLLM: return llm_factory.get_llm()
设计要点：单例模式，整个进程共享一个 LLM 实例。切换 provider 只需改 config/settings.py 中的 LLM_PROVIDER。

4. BaseAgent 基类 — base_agent.py

所有 Agent 的父类，通过 LangChainAgentWrapper 与 LLM 交互

src/agents/base_agent.py
class BaseAgent(ABC): def __init__(self, agent_id, name, role, llm=None): self.agent_id = agent_id # "document_parser" self.name = name # "文档解析Agent" self.role = role # 用于路由查找 self.llm = llm or get_llm() # LangChain LLM 实例 async def chat(self, message, system_prompt=None) -> str: """与LLM异步对话（通过 LangChainAgentWrapper）""" return await self.wrapper.achat(message, system_prompt) @abstractmethod async def process(self, task: Dict) -> Dict: """每个子类必须实现""" pass
LLM 交互链路：Agent.process() → self.chat(msg, prompt) → LangChainAgentWrapper.achat() → llm.ainvoke(messages) → extract_llm_content() 处理响应格式。

5. IntentRecognizer — 意图识别

基于 LLM Function Calling 的意图分类，零关键词匹配

src/agents/intent_recognizer.py — Function Calling 模型
class IntentResult(BaseModel): """意图识别结果（用于 Function Calling）""" intent: IntentType # 意图类型枚举 confidence: float # 置信度 0.0-1.0 entities: Dict # 提取的实体 reasoning: str # 判断理由
intent_recognizer.py — 识别流程
async def _recognize_by_function_calling(self, text, context): # 使用 with_structured_output 获取结构化输出 structured_llm = self.llm.with_structured_output(IntentResult) messages = [HumanMessage(content="""你是一个意图识别专家... 核心规则（按优先级）： 1. 用户打招呼 → greeting 2. 用户追问之前的结果 → question_answer 3. 用户提到"风险" → risk_assessment 4. 用户提到"合规" → compliance_check 5. 用户提到"条款" → clause_analysis 6. 只有明确说"完整审查" → contract_review 7. 其他提问 → question_answer 用户输入: {text}""")] result = await structured_llm.ainvoke(messages) return Intent(type=result.intent, confidence=result.confidence, ...)
意图类型判断规则路由目标需要合同
contract_review明确要求"完整/全面/整体审查"4个 Agent 并行是
risk_assessment提到"风险"RiskAssessmentAgent是
compliance_check提到"合规/合法"ComplianceCheckerAgent是
clause_analysis提到"条款"ClauseAnalysisAgent是
report_generation要求生成/导出报告ReportGeneratorAgent否
question_answer追问、提问（默认）LLM 直接回答否
greeting打招呼直接回复否
关键设计：100% LLM 驱动，零关键词匹配。with_structured_output() 让 LLM 直接输出 Pydantic 模型，无需正则解析。上下文感知（上一轮意图、是否已有合同文本、对话轮数）。

6. MultiTurnHandler — 核心调度器

意图识别 → Agent 路由 → 并行执行 → 结果存储 → 回复生成

MultiTurnHandler 执行流程
用户发送消息
↓
ctx.add_user_message()
存储到 ConversationContext._messages
↓
IntentRecognizer.recognize()
LLM Function Calling 识别意图
↓
INTENT_AGENT_ROUTING[intent]
静态路由表查找目标 Agent
↓
根据意图类型分支：
contract_review
4个Agent并行
risk/clause/compliance
单Agent执行
question_answer
LLM直接回答
↓
ctx.set_agent_result()
结果存入 _turns[*].agent_results
↓
返回结果 + 格式化回复
multi_turn_handler.py — 路由表
# 意图到 Agent 的静态路由映射 INTENT_AGENT_ROUTING = { IntentType.CONTRACT_REVIEW: { "agents": ["document_parser", "clause_analyst", "risk_assessor", "compliance_checker"], "parallel": True, # 4个Agent并行执行 }, IntentType.RISK_ASSESSMENT: { "agents": ["risk_assessor"], }, IntentType.QUESTION_ANSWER: { "agents": [], # 无Agent，LLM直接回答 "direct_response": True, }, # ... 其他意图 }
multi_turn_handler.py — 追问处理
async def _answer_from_context(self, user_message, ctx): # 只用两个字段构建上下文： # 1. 合同内容 contract_text = ctx.get_contract_text() # → _shared_data["contract_text"] # 2. 对话历史 messages = ctx.get_messages() # → _messages # 发给 LLM 生成回答 response = await llm.ainvoke([ SystemMessage(content="你是一个合同审查助手..."), HumanMessage(content=f"{上下文}\n\n用户问题：{user_message}") ]) return response.content
追问机制：追问（question_answer）不读取 Agent 原始结果，而是用合同文本 + 对话历史（_messages）构建上下文，让 LLM 直接回答。因为 _messages 中助手的回复已经包含了格式化的分析结果。

7. DocumentParserAgent — 文档解析

LLM 驱动的合同结构化信息提取，支持长文本 Map-Reduce

document_parser_agent.py
async def process(self, task): contract_text = task.get("contract_text") if len(contract_text) > self.chunk_size: # 12000 字符 return await self._map_reduce_extract(contract_text) return await self._llm_extract_all(contract_text) async def _llm_extract_all(self, text): # 单次 LLM 调用提取：basic_info, sections, dates, amounts, definitions content = await self.chat(user_message, system_prompt) return parse_json_from_llm(content)
Map-Reduce：超过 12000 字符时，按条款边界语义分块 → 每块并行 LLM 提取 → 合并去重。短文本直接一次 LLM 调用。

8. RiskAssessmentAgent — 风险评估

纯 LLM 风险识别 + 量化评分 + 缓解建议

risk_assessment_agent.py
async def process(self, task): text = task.get("contract_text") # 纯 LLM 评估（无正则回退） result = await self._assess_with_llm(text, contract_type) # 风险量化 + 缓解建议 result["risk_quantification"] = self.quantify_risk(result.get("risks", [])) result["mitigation_plan"] = self.suggest_mitigation(result.get("risks", [])) return result def quantify_risk(self, risks): # severity(high=3,medium=2,low=1) × category权重(liability=1.5,...) # 归一化到 0-100 分
风险量化：每个风险按 severity × category 权重计算加权分数，归一化到 0-100 分。高/中风险自动生成缓解建议模板。

10. ComplianceCheckerAgent — 合规检查

LLM 驱动的法规合规检查

compliance_checker_agent.py
class ComplianceCheckerAgent(BaseAgent): # 必备条款定义（仅作为 LLM prompt 上下文，不用于关键词匹配） REQUIRED_CLAUSES = { "sales": ["标的物", "价款", "交付", "验收", "违约责任", "争议解决"], "service": ["服务内容", "服务期限", "服务费用", "验收标准", "违约责任", "保密"], "labor": ["工作内容", "劳动报酬", "工作时间", "社会保险", "劳动保护", "解除条件"], # ... 其他类型 } async def _check_with_llm(self, text, contract_type): # 将 REQUIRED_CLAUSES 注入 prompt，由 LLM 判断 required = self.REQUIRED_CLAUSES.get(contract_type, ...) system_prompt = f"""...该类型合同必备条款: {', '.join(required)}...""" content = await self.chat(user_message, system_prompt)
设计决策：REQUIRED_CLAUSES 字典仅作为 LLM prompt 的上下文参考，不用于关键词匹配。LLM 综合判断必备条款是否缺失、是否违规。

13. 四层记忆系统

设计了 4 层，实际在用 2 层

Context

对话上下文

ConversationContext — 消息历史 + 意图链 + Agent 结果（_turns）+ 共享数据（_shared_data）。核心在用。

LongTerm

长期记忆

LongTermMemory — Qdrant 向量持久化：审查历史 + 用户偏好。支持跨会话语义检索。核心在用。

Private

私有记忆

BaseAgent.private_memory 字典。已定义但未接入。

Shared

共享记忆

SharedMemoryManager。已定义但未接入，Agent 间数据通过 _shared_data 传递。

ConversationContext — 核心数据结构
class ConversationContext: _messages: deque # 对话历史 (用户+助手) _turns: List[TurnContext] # 每轮对话记录 # TurnContext.intent = 该轮意图 # TurnContext.agent_results = 该轮 Agent 结果 ← Agent 结果存在这里 _shared_data: Dict # Agent 间共享数据 # "contract_text" = 合同文本 # "parsed_result" = Agent 间传递的中间数据 _intent_chain: List[str] # 意图序列 def set_agent_result(self, agent_name, result): # 只写 _turns，不写 _shared_data self._current_turn.agent_results[agent_name] = result def get_all_results(self): # 从所有 _turns 收集 Agent 结果 results = {} for turn in self._turns: results.update(turn.agent_results) return results
