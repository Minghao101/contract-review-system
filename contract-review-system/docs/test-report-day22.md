## 模块说明

### 1. 意图识别器 (`src/agents/intent_recognizer.py`)
- **IntentType 枚举**: 8种意图类型（合同审查、条款分析、风险评估、合规检查、报告生成、问题回答、问候、未知）
- **Intent 数据类**: 封装意图识别结果，支持序列化
- **IntentRecognizer 类**: 支持 keyword/llm/hybrid 三种识别模式
- **关键词规则**: 基于关键词匹配和正则表达式模式匹配
- **自定义规则**: 支持运行时添加自定义关键词和模式

### 2. 对话上下文管理 (`src/agents/conversation_context.py`)
- **ConversationContext**: 单会话上下文管理，包括消息历史、意图链、Agent结果、文件上传
- **ConversationManager**: 多会话管理器，支持会话创建、获取、移除
- **Message/TurnContext**: 消息和轮次上下文数据结构
- **序列化**: 支持 dict 序列化/反序列化和文件持久化

## 修复的问题

### Bug 1: ConversationContext `_metadata` 初始化顺序
- **问题**: `self.session_id` 赋值触发 property setter，setter 访问 `self._metadata`，但 `_metadata` 尚未初始化
- **修复**: 将 `_metadata` 初始化移到 `session_id` 赋值之前

### Bug 2: RISK_ASSESSMENT 关键词和模式匹配
- **问题**: "风险"不是独立关键词，正则模式 `{0,3}` 太严格
- **修复**: 添加"风险"为独立关键词，放宽模式为 `{0,10}`，新增"看看/查看/了解风险"模式

### Bug 3: CONTRACT_REVIEW 短文本降级逻辑
- **问题**: 短文本(<50字符)置信度减半后低于阈值，被错误降级为 QUESTION_ANSWER
- **修复**: 移除降级逻辑，仅降低置信度而不改变意图类型

### Bug 4: CONTRACT_REVIEW 模式冲突
- **问题**: `合同.{0,5}(条款|风险|问题|内容)` 模式中的"风险"与 RISK_ASSESSMENT 冲突
- **修复**: 从 CONTRACT_REVIEW 模式中移除"风险"选项
