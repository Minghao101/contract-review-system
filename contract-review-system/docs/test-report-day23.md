## 模块说明

### 多轮对话处理器 (`src/agents/multi_turn_handler.py`)

- **MultiTurnHandler**: 核心多轮对话处理器，整合意图识别和对话上下文管理
- **INTENT_AGENT_ROUTING**: 意图到Agent的路由映射表
- **FOLLOW_UP_RULES**: 追问场景的上下文注入规则
- **模拟Agent执行**: 支持注册自定义回调或使用模拟结果

### 功能特性

| 功能 | 说明 |
|------|------|
| 对话历史存储 | 基于ConversationContext的消息历史管理 |
| 上下文注入 | 自动注入合同文本、历史Agent结果到后续请求 |
| 意图路由 | 8种意图到6个Agent的智能路由 |
| 追问支持 | 解析→风险→条款→报告的完整追问链 |
| 自定义回调 | 支持注册实际Agent执行回调 |
| 多会话隔离 | 每个session独立的上下文和历史 |
| 回复格式化 | 根据意图类型生成用户友好的回复 |

## 多轮对话流程示例

```
第1轮: 问候
  用户: "你好"
  系统: IntentType.GREETING → system Agent → 问候回复

第2轮: 上传合同
  用户: "帮我审查合同" (contract_text="技术服务合同...")
  系统: IntentType.CONTRACT_REVIEW → coordinator Agent → 审查结果

第3轮: 追问风险
  用户: "有什么风险"
  系统: IntentType.RISK_ASSESSMENT → risk_assessor Agent
        → 自动注入合同文本和历史结果 → 风险评估结果

第4轮: 生成报告
  用户: "生成报告"
  系统: IntentType.REPORT_GENERATION → report_generator Agent
        → 汇总所有已有分析结果 → 综合报告
```
