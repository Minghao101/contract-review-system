## 修复的问题

### 1. 除零错误
- **问题**: `get_overall_progress()` 方法在空步骤列表时可能除零
- **修复**: 添加额外的空列表检查 `if self.steps else 0`

### 2. 字符串拼接语法错误
- **问题**: f-string中括号被解释为函数调用
- **修复**: 将条件表达式改为if-else语句块

### 3. 空步骤列表初始化问题
- **问题**: `ReviewProgressTracker(steps=[])` 初始化时，空列表被当作falsy值
- **修复**: 将 `self.steps = steps or REVIEW_STEPS.copy()` 改为 `self.steps = steps if steps is not None else REVIEW_STEPS.copy()`
