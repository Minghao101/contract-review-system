节点详情

🚀 START / END

工作流的入口和出口点。LangGraph 自动管理状态的初始化和清理。

📥 process_user_input

处理用户输入，添加到对话历史，更新轮次计数器。

状态：turn_count += 1

🧠 recognize_intent

使用 LLM Function Calling 识别用户意图，支持 10+ 种意图类型。

输出：intent_type, confidence

🔀 route_by_intent

根据意图类型和对话状态路由到对应处理节点。

特殊逻辑：awaiting_follow_up 时强制走 follow_up

📊 execute_analysis_agents

并行执行多个分析 Agent（风险评估、条款分析、合规检查等）。

使用：asyncio.gather 并行执行

💬 handle_follow_up

处理用户追问，利用对话历史和合同内容生成详细回答。

完成后设置：awaiting_follow_up = True

📝 handle_topic_discussion

多 Agent 讨论具体议题，生成综合结论。

参与者：risk_assessor, clause_analyst, compliance_checker

💬 generate_response

根据 Agent 结果生成用户友好的回复，格式化输出。

风险评估后设置：awaiting_follow_up = True

意图路由映射

意图类型 路由路径 触发条件
contract_review analysis 完整审查、全面审查、整体审查
risk_assessment analysis 风险、评估风险、分析风险
clause_analysis analysis 条款、分析条款
compliance_check analysis 合规、合法、检查合规
modify_contract analysis 修改条款、删除条款、增加条款
question_answer follow_up 追问、解释、为什么
topic_raise topic 讨论某条款、分析某风险点
topic_follow_up topic 假设性分析、换个角度
greeting direct 打招呼
